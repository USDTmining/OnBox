# OnBox

Modern movie & TV streaming web app.

## Features
- Browse trending, popular, top-rated movies & TV shows
- Search and Discover
- Personal watchlist (local + Firebase)
- **Continue Watching** — resume from where you left off
- Multiple embed sources with easy switching
- PWA install support
- Dark / light theme

## Stack
Vanilla JS · Firebase · TMDB · Vercel

## Run
Open `index.html` or deploy the folder to Vercel.
